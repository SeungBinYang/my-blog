{%- comment -%} Hero graphic: the blog owner's own skateboard -- a royal blue "grit" deck seen from underneath, traced from a photo of the real board. Inline SVG rather than an image file on purpose -- it paints from the --deck-* tokens, so there is no asset to keep in sync with the palette. The board is a physical object, so those tokens are the same in both themes. 1 unit is about 1mm: the deck is 788 x 200 (8" x 31"). Construction notes, since the geometry is measured rather than eyeballed (the photo was levelled -- it sat 1.04 deg off -- and rescaled so the rails land on y=50 and y=250): - Nose and tail are true semicircles of radius 100; the photo fits a circle to within a unit. - "grit" is drawn as outlines, not text, so it renders the same with or without web fonts. They start from Abril Fatface (SIL OFL 1.1), set at 208 units and rotated -8.25 deg like the print, then every segment was moved onto the letter edge measured in the photo (IoU 0.80 -> 0.92). Two glyphs were redrawn where the print differs from the font: the g has a pendant ball ear instead of Abril's curl, and the t rises from its flag in one concave wedge instead of a stem with a flat top. - The lettering is clipped to the deck, so the g's loop runs off the bottom rail and the i's dot and the t's top run off the top one; the t's tail sits under the tail truck, as on the real board. - Trucks are symmetric about the deck centre (x=450): axle at 207, kingpin at 228, bolts 43 apart. The tail truck is the nose truck mirrored, which also mirrors which side of the hanger catches light, as it does in the photo. It is built as a real object in CSS 3D, not two flat pictures: the art and griptape faces sit 12 units apart with five plies between them, and the trucks stand off the deck at their real heights (baseplate 12, bushings 22-40, hanger 46-60, kingpin nut 66). Each wheel is a 54-unit cylinder: seven slices make the tread, shaded like a cylinder seen from below, and two discs at right angles to them make the sides, so turned side-on it shows a round wheel with its bearing. --z on a layer is its height in units; .deck-flip turns those into pixels with container units, so the depth scales with the board. Click it and it kickflips. The script below samples the trick into keyframes for the Web Animations API: the ollie on .deck-pop, the roll on .deck-flip, and the shading of each face, which is worked out from where its normal points relative to a light above the viewer.
