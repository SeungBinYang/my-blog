{%- comment -%} Hero graphic: the blog owner's own skateboard -- a royal blue "grit" deck seen from underneath, traced from a photo of the real board. Inline SVG rather than an image file on purpose -- it paints from the --deck-* tokens, so there is no asset to keep in sync with the palette. The board is a physical object, so those tokens are the same in both themes. 1 unit is about 1mm: the deck is 788 x 200 (8" x 31"). Construction notes, since the geometry is measured rather than eyeballed (the photo was levelled -- it sat 1.04 deg off -- and rescaled so the rails land on y=50 and y=250): - Nose and tail are true semicircles of radius 100; the photo fits a circle to within a unit. - "grit" is drawn as outlines, not text, so it renders the same with or without web fonts. They start from Abril Fatface (SIL OFL 1.1), set at 208 units and rotated -8.25 deg like the print, then every segment was moved onto the letter edge measured in the photo (IoU 0.80 -> 0.92). Two glyphs were redrawn where the print differs from the font: the g has a pendant ball ear instead of Abril's curl, and the t rises from its flag in one concave wedge instead of a stem with a flat top. - The lettering is clipped to the deck, so the g's loop runs off the bottom rail and the i's dot and the t's top run off the top one; the t's tail sits under the tail truck, as on the real board. - Trucks are symmetric about the deck centre (x=450): axle at 207, kingpin at 228, bolts 43 apart. The tail truck is the nose truck mirrored, which also mirrors which side of the hanger catches light, as it does in the photo. Click it and it kickflips: .deck-pop carries the ollie (pop, nose up, level out, land) and .deck-flip the 360 deg roll about the long axis, so each gets its own easing. Mid-roll the board shows its griptape face (wheels peeking past the rails, eight bolt heads). There is no edge plane for the side-on instant: one through the middle shows through the faces at shallow angles, and the board is edge-on for under a frame. The drawings are decorative and hidden from assistive tech; the button around them is labelled, so the trick is reachable from the keyboard. {%- endcomment -%}
